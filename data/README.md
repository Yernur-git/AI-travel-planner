# Первый снимок каталога Алматы

Владелец: Ернур. Проверка публичных страниц выполнена 16 ноября 2026 года; отметка завершения сверки снимка — `2026-11-16T22:53:58+05:00` в `sources.json`. Это проверка опубликованного текста через веб-инструмент, а не звонок, посещение или гарантия будущего тарифа. У веб-инструмента может быть кеш. Время публикации/окончания действия не установлено: `published_at` и `valid_until` равны null, даже если на странице есть дата без времени.

## Файлы и граница контракта

- `places.json`: массив существующих `Place` из `src/contracts/models.py`.
- `sources.json`: массив существующих `Source`; `supports` связывает конкретный факт с `place_id` или `basis_id`, а не просто с сайтом.
- `src/catalog/`: локальная загрузка, проверки реестров, поиск и CLI. Общие модели и `docs/CONTRACT.md` не изменены.

Версия снимка вычисляется как `sha256` байтов `places.json`, нулевого разделителя и `sources.json`. Изменение любого файла, включая форматирование, меняет версию. Это идентификатор данных, не версия общего контракта. Модуль не читает `.env`, не обращается к сети и не генерирует маршрут.

Все URL, издатели и короткие извлечения находятся в [реестре источников](sources.json). Для числовых координат DMS переведены в десятичные градусы и округлены до шести знаков; для центрального музея использованы опубликованные десятичные координаты. Это точки объектов, не проверенные входы и не маршруты переходов. Конфликт координат Кастеева требует ручной проверки по дополнительному первичному источнику.

`reported_coordinates`, `reported_opening_hours`, `reported_tariff` в `Source.supports.field` — текстовые свидетельства/расхождения, разрешённые строковым SupportedFact. Они не являются новыми полями Place и не используются фильтром как подтверждённые интервалы/цены. Источники с такими записями возвращаются поиском вместе с местом, чтобы потребитель видел ограничения. Известные тарифы имеют условия в `entry_price.assumption`: до бюджетной интеграции нужно согласовать категорию посетителя. Каталог не гарантирует применимость тарифа к любому взрослому.

Интересы — редакционная классификация в пределах существующих кодов контракта. Длительности — **редакционные оценки автора снимка**: 90 минут для Кастеева, ботсада и центрального музея, 60 минут для Ыхласа и парка. Метод: начальный резерв 1–1,5 часа на осмотр/прогулку без очередей, экскурсий и переходов; темп не измерялся. Поэтому `fact_source_ids.visit_duration_minutes=[]`. Это не сведения сайтов и не результаты evaluation.

## Поиск и ошибки

`load_catalog(data_dir=...)` принимает каталог с двумя JSON-файлами; без аргумента путь привязан к модулю, а не текущей папке. Ошибки чтения, JSON, Pydantic и ссылок выдаются как `CatalogError`. Проверяются уникальные ID и JSON-ключи, ссылки на сущности и источники, поддержка именно нужного поля, наличие свидетельств названия/известного адреса/координат/часов/опубликованной цены, пересечения интервалов. Загрузчик не может доказать смысл извлечения или актуальность сайта: сверка значения с URL остаётся ручной.

`catalog.search(query='', interests=None, match='any', start_date=None, end_date=None, include_unknown_hours=True)` возвращает `CatalogSelection`: копии выбранных `Place`, относящиеся к ним `Source` (supports ограничен выбранными сущностями), `catalog_version`.

- Текст: подстрока в названии или адресе; без учёта регистра, ё/е и лишних пробелов. Перевод/транслитерация и поиск по описаниям не реализованы.
- Интересы: `any` — хотя бы один; `all` — все. Пустой список не ограничивает. Неизвестные и повторные теги — ошибка. Порядок совпадает с JSON.
- Даты: 1–3 включительных дня, одна start_date означает один день; end_date без start_date — ошибка. Исключение даты приоритетнее weekly. `[]` означает закрыто, null/отсутствие — неизвестно. Место остаётся, если хотя бы в один день открыто или неизвестно. `include_unknown_hours=False` требует дату и оставляет только места с известным открытым днём.
- Результат — кандидаты. Интервалы визита, длительность, касса, переходы, праздники, будущие изменения, полный бюджет и доступность на каждый день не проверяются. Это не ScheduleCheck и не baseline-маршрут.

## Как добавить остальные места

1. Открыть публичную страницу оператора и при необходимости независимый источник координат. Проверить условия использования; при запрете/неясности не копировать материалы, подобрать источник либо уточнить права. Отказ доступа не обходить и не заменять поисковым фрагментом.
2. Добавить Source с уникальным ID, реальным URL, издателем, фактическим checked_at со смещением и краткими supports для нужного place_id/basis_id. Не обновлять checked_at старых источников без повторного просмотра. Даты публикации без времени сохранить текстом, не выдумывать полночь.
3. Добавить Place со стабильным ID и entry CostBasis с отдельным ID. Неизвестные значения — null/unknown. Нулевую цену ставить только с подтверждением бесплатности. Тариф и условия аудитории, дополнительные услуги, даты/исключения сверять отдельно.
4. Для каждого известного факта прописать его source_ids. Редакционные теги/длительность описать здесь; не ссылаться на сайт как на автора оценки. При расхождении сохранить оба свидетельства, спорное поле оставить null до разрешения.
5. Запустить команды ниже и просмотреть результат поиска. Проверить поддержку значений URL вручную; успешный pytest не подтверждает реальные факты. Не менять общие модели без согласования обоих участников.

```powershell
.\.venv\Scripts\python.exe -m src.catalog --interest nature
.\.venv\Scripts\python.exe -m src.catalog --query Кастеева
.\.venv\Scripts\python.exe -m src.catalog --start-date 2026-11-17 --known-hours-only
.\.venv\Scripts\python.exe -m src.catalog --start-date 2026-11-18 --known-hours-only
.\.venv\Scripts\python.exe -m pytest tests/test_catalog.py -q
.\.venv\Scripts\python.exe -m pytest -q
```

Ожидания CLI: nature — ботсад и парк; поиск Кастеева — одно место; 17 ноября (вторник) с known-hours-only — пусто, 18 ноября — центральный музей. Без known-hours-only неизвестные часы сохраняются.

## Материалы и права

Сохраняются названия и отдельные факты в собственном структурированном изложении; фотографии, отзывы и тексты статей не копировались. Атрибуция каждого источника — publisher и URL в sources.json. У Википедии просмотрена отметка CC BY-SA; [условия Википедии](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) и лицензии могут требовать дополнительных действий при использовании текста/изображений. Наличие ссылки не даёт прав на весь сайт.

У операторов и туристических порталов встречается «все права защищены»; отдельное разрешение на публикацию материалов не получено. Страница [правил Kazakhstan.travel](https://kazakhstan.travel/ru/terms) обнаружена, повторное чтение завершилось таймаутом; полная проверка условий повторного использования остаётся открытой перед публикацией/расширением. Этот снимок не означает наличие лицензии на чужие статьи или подтверждение юридической проверки. В этой задаче публикация не выполнялась.
