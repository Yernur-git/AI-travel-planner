# Сессия 004: первое реальное подключение Gemini

Дата: 25 ноября 2026. Это краткое резюме реальной сессии, не дословная расшифровка и не полный экспорт. Секреты в резюме не включались. Ветка feature/gemini-planner. Ернур поручил подключить только Free tier и запретил изменения app.py, UI, бюджета Рахата, commit/push/merge.

Прочитаны правила, план, решения, контракт, каталог. В начальной чистой рабочей копии ключа не было; проверены игнорирование .env и пустой шаблон. Стандартный шаблон Google API key не найден в отслеживаемых файлах и 7 доступных коммитах; это ограниченный поиск одного формата. По официальной документации выбрана gemini-3.5-flash-lite с бесплатными входными/выходными токенами. Пользователь самостоятельно сохранил .env и подтвердил Free без billing. Ключ в чат не передавался, его значение команды не печатали.

Добавлены официальный SDK google-genai 3.6.1, python-dotenv 1.2.4, провайдер, отдельный CLI, пример TripRequest и offline-тесты. Проверяется существующий PlanDraft без изменения контракта. Модель выбирает реальные ID; текстовые утверждения заменяются контролируемыми объяснениями, факты и URL берутся из каталога. Есть предел 1–3 генерации, таймаут 45 секунд и безопасные коды ошибок; сервисные ошибки не повторяются автоматически. Демо не используется как fallback.

Два ранних CLI завершились SERVICE_UNAVAILABLE; отдельная диагностика получила completed без проверки/сохранения содержимого; следующая диагностика получила HTTP 503. Финальный CLI с пределом 2 выполнил две генерации: первая не прошла проверку, вторая принята.
- Сохранён нормализованный живой результат `eval/results/gemini-first.json`: центральный музей, питание, Ыхлас на 26 ноября. Его PlanDraft и ResultMetadata повторно проверены кодом; секрет в сохраняемом JSON отсутствовал. Сырой текст ответов и исключений не сохранялся.
- Финальная проверка: git diff --check без ошибок, все локальные Markdown-ссылки изменённых документов существуют. Точное значение локального ключа и стандартный шаблон Google API key не найдены среди отслеживаемых и неигнорируемых новых файлов; .env игнорируется. Это проверка кандидатов Git, не всех файлов компьютера. Защищённые файлы без изменений.
