## Реально выполненные проверки

Среда: Windows, Python 3.11.9. Прямые зависимости: Streamlit 1.67.0, Pydantic 2.14.3, tzdata 2026.6, pytest 9.2.0. Транзитивные зависимости отдельно не заморожены.

1. `python -m venv .venv` и установка через Python окружения с requirements-dev.txt завершились успешно.
2. Первый запуск `python -m pytest -q`: 45 passed in 1.17s. Проверялись типы, даты/диапазон, неизвестные расходы, структура источников/каталога, ID, статусы и кнопка Streamlit через AppTest.
3. При просмотре замечен недостающий инвариант BudgetSummary: переданный статус должен соответствовать известной части/итогу и лимиту. Добавлена проверка статуса без реализации расчёта позиций и регрессионный тест. Итоговый повторный запуск: **46 passed in 1.26s**.
4. `python -m pip check`: No broken requirements found. `git diff --check`: без ошибок; Git вывел только предупреждения о будущем преобразовании LF в CRLF.
5. Streamlit запущен на 127.0.0.1:8501. HTTP-запрос к /_stcore/health вернул 200, тело ok.
6. Через Playwright CLI в настоящем браузере открыта страница, проверена видимая пометка про Gemini, нажата кнопка демо, раскрыт полный ответ. Snapshot показал partial, неизвестные расходы, 0 источников и условное место. Консоль: 0 ошибок и предупреждений. Просмотрены скриншоты верхней части и результата; диагностические файлы находятся в игнорируемых output/playwright/ и .playwright-cli/.

Демо не закрывает checkpoint; 10-запросная оценка AI остаётся отдельной обязательной задачей финальной сдачи.
