# Реальные сессии работы с агентом

Курс требует 3–5 ключевых сессий, показывающих работу команды с агентом. Папка создана на этапе подготовки; требование ещё не выполнено.

`001-planning-summary.md` — краткое резюме реальной сессии подготовки. `002-foundation-summary.md` — резюме следующей реальной задачи общей основы. Это не полные экспорты. Не утверждать, что преподаватель принимает такой формат как transcript/export: для сдачи сохранить настоящие экспорты ключевых сессий. Не создавать дополнительные вымышленные записи ради количества.

`003-catalog-summary.md` — резюме реальной сессии Ернура: первые 5 мест Алматы, источники, загрузка/поиск и проверки. Это также не полный экспорт. Оно не подтверждает выполнение требования курса о числе и формате логов.

В репозитории также есть предоставленный участником `01-project-planning-yernur.md` с пометкой Transcript первой сессии. Он и `001-planning-summary.md` описывают одну сессию и не считаются двумя отдельными. Полнота этого transcript не проверялась, файл в задаче основы не редактировался. Для новой задачи основы пока добавлено только резюме; критерий 3–5 реальных ключевых сессий остаётся открытым.

Рекомендуемые реальные сессии: планирование; сквозная интеграция; исправление обнаруженной ошибки; AI evaluation; итоговая проверка. Выбирать по фактической полезности, а не создавать пять файлов заранее.

Для каждого сохранённого экспорта указывать дату, участника, инструмент, задачу, исходный запрос, важные действия/ответы, изменённые файлы и настоящие проверки. Отмечать пропуски и удаление секретов. Не сохранять ключи, токены, персональные данные и содержимое `.env`. Коммиты и результаты добавлять только после их появления. Каждый участник должен быть представлен своей реальной работой.
